# Data Model

## English

The mockup uses synthetic demo data only.

The minimum scientific-operational model is based on:

- installation;
- location;
- monitoring event;
- evidence asset;
- measurement;
- biodiversity observation;
- review status;
- uncertainty note;
- exportable report.

The goal is not to model Ocean Ecostructures internal systems. The goal is to demonstrate how a scientist could query a data point and understand where it comes from, how it was measured, what evidence supports it, what uncertainty exists and whether it can be exported.
