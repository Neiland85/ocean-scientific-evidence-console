# Traceability Flow

## English

The mockup follows this scientific-operational chain:

Installation → Monitoring event → Evidence asset → Measurement → Review status → Uncertainty note → Exportable report

Every visible indicator should be connected to:

- date;
- location;
- method;
- source;
- evidence reference;
- review status;
- uncertainty;
- export version.

A scientist should be able to ask:

"Where does this data come from, how was it measured, what evidence supports it, who reviewed it, what uncertainty exists and can I export it?"

## Català

El mockup segueix aquesta cadena científic-operativa:

Instal·lació → Esdeveniment de monitoratge → Actiu d'evidència → Mesura → Estat de revisió → Nota d'incertesa → Informe exportable

Cada indicador visible ha d'estar connectat amb:

- data;
- ubicació;
- mètode;
- font;
- referència d'evidència;
- estat de revisió;
- incertesa;
- versió d'exportació.

Un científic hauria de poder preguntar:

"D'on prové aquesta dada, com s'ha mesurat, quina evidència la suporta, qui l'ha revisat, quina incertesa existeix i puc exportar-la?"

## Español

El mockup sigue esta cadena científico-operativa:

Instalación → Evento de monitorización → Activo de evidencia → Medición → Estado de revisión → Nota de incertidumbre → Reporte exportable

Cada indicador visible debe estar conectado con:

- fecha;
- ubicación;
- método;
- fuente;
- referencia de evidencia;
- estado de revisión;
- incertidumbre;
- versión de exportación.

Un científico debería poder preguntar:

"¿De dónde sale este dato, cómo se midió, qué evidencia lo respalda, quién lo revisó, qué incertidumbre existe y puedo exportarlo?"
