# UI Language Switch

## English

The application UI uses an internal language switch for English, Catalan and Spanish.

Browser-level automatic translation remains disabled to avoid React hydration mismatches.

The main implementation language remains English.

## Català

La interfície de l'aplicació utilitza un selector intern d'idioma per a anglès, català i castellà.

La traducció automàtica del navegador continua desactivada per evitar desajustos d'hidratació de React.

La llengua principal d'implementació continua sent l'anglès.

## Español

La interfaz de la aplicación utiliza un selector interno de idioma para inglés, catalán y español.

La traducción automática del navegador sigue desactivada para evitar errores de hidratación de React.

El idioma principal de implementación sigue siendo el inglés.
