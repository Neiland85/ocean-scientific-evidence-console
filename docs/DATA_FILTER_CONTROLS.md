# Data Filter Controls

## English

The mockup includes scientific data filter controls to help a scientist reduce the visible synthetic monitoring records without losing traceability.

Initial filters:

- All
- Reviewed
- Partial review
- With evidence
- With uncertainty
- Exportable

The goal is not to create a full analytics engine. The goal is to demonstrate that scientific-operational data should be explorable by review state, evidence availability, uncertainty and export readiness.
