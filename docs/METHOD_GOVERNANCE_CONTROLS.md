# Method Governance Controls

## English

The console includes interactive synthetic method governance controls.

The scientist can change method parameters and immediately see whether each governance gate passes or requires review.

Parameters:

- Method visibility
- Evidence traceability
- Uncertainty clarity
- Review completeness
- Sensor calibration
- Export readiness

Green means the parameter passes the acceptance threshold. Red means the parameter requires review.

No real Ocean Ecostructures data is used.
