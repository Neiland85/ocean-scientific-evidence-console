# Release v0.3.1 — NDA Governance Snapshots & Printable Report

## Scope

This release packages the NDA-safe scientific evidence console as a professional static mockup for scientific method governance review.

The application uses synthetic demo data only. No real Ocean Ecostructures operational data, measurements, evidence, locations, private methods or NDA-protected records are included.

## Main capabilities

- Scientific evidence console with multilingual UI: English, Catalan and Spanish.
- Synthetic scientific data filters.
- Pseudo-3D visual filter cards.
- Synthetic operational insight panel by active filter.
- Interactive canonical method governance controls.
- Red / green governance gate scoring.
- Freeze exact governance parameter configurations.
- Local comparison dashboard for frozen configurations.
- Reapply or remove saved governance snapshots.
- Browser print flow for the selected global governance parameter report.
