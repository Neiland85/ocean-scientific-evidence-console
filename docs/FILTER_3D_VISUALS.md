# Filter 3D Visuals

## English

The filter controls use lightweight pseudo-3D microcharts.

They are implemented with React, SVG and CSS/Tailwind classes. No charting library, 3D engine, canvas dependency or real data source is introduced.

Purpose:

- make scientific filters visually scannable;
- show a more modern product surface;
- preserve static, local and NDA-safe execution;
- avoid heavy visual dependencies.
