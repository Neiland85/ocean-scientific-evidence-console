# Governance Snapshots and Reports

## English

The console allows freezing exact synthetic method governance parameters.

Frozen configurations are stored locally in the browser and shown in a comparison dashboard.

A reviewer can:

- freeze the current parameter set;
- compare frozen configurations;
- reapply a frozen configuration;
- remove a frozen configuration;
- print a governance report with the selected global parameters.

No real Ocean Ecostructures data is used.

## Català

La consola permet congelar paràmetres exactes de governança sintètica del mètode.

Les configuracions congelades es guarden localment al navegador i es mostren en un dashboard comparatiu.

Un revisor pot:

- congelar el conjunt actual de paràmetres;
- comparar configuracions congelades;
- reaplicar una configuració congelada;
- eliminar una configuració congelada;
- imprimir un informe de governança amb els paràmetres globals seleccionats.

No s'utilitzen dades reals d'Ocean Ecostructures.
