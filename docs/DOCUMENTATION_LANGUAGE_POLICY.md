# Documentation Language Policy

## English

The main language of the project is English.

All strategic, documentary and client-facing documentation must follow this order:

1. English
2. Catalan
3. Spanish

This order is intentional: international technical clarity first, Catalan institutional proximity second, and Spanish operational accessibility third.

## Català

La llengua principal del projecte és l'anglès.

Tota la documentació estratègica, documental i orientada al client ha de seguir aquest ordre:

1. Anglès
2. Català
3. Castellà

Aquest ordre és intencionat: claredat tècnica internacional primer, proximitat institucional catalana després i accessibilitat operativa en castellà finalment.

## Español

El idioma principal del proyecto es el inglés.

Toda la documentación estratégica, documental y orientada al cliente debe seguir este orden:

1. Inglés
2. Catalán
3. Español

Este orden es intencional: claridad técnica internacional primero, proximidad institucional catalana después y accesibilidad operativa en español finalmente.
